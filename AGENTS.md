# Agents

Before generating or restyling UI in this repository or a fork:

1. Read [`skill/white-baggage-tag-aesthetic/SKILL.md`](skill/white-baggage-tag-aesthetic/SKILL.md).
2. Use [`design-tokens/tokens.css`](design-tokens/tokens.css). Do not invent a palette.
3. Declare `size` and `domain` on every new block.
4. Run [`docs/critique-checklist.md`](docs/critique-checklist.md). Fail = remove, merge, or resize.
5. Do not commit secrets or live bag data.

Human door: [`START-HERE.md`](START-HERE.md).
