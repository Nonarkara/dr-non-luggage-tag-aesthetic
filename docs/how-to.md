# How to apply

## Human, 15 minutes

1. Open [`START-HERE.md`](../START-HERE.md).
2. Open [`examples/gallery/index.html`](../examples/gallery/index.html) in a browser (file:// is enough).
3. Copy `design-tokens/tokens.css` and `components/tag-system.css` into the surface you are designing.
4. Put **one destination noun** at primary size. Put **one stable id** in mono. Put context third. Put a human fallback. Put a receipt.
5. Run [`critique-checklist.md`](critique-checklist.md). Fail = remove, merge, or resize.

## Agent

Load [`skill/white-baggage-tag-aesthetic/SKILL.md`](../skill/white-baggage-tag-aesthetic/SKILL.md). Do not invent a second palette. Do not add slogans. Declare `size` and `domain` in markup comments.
