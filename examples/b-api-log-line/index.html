Example B · API response / log line

One line. Same package.

A log line is a tag at 12 pt. Destination first, LPN second, context third, human fallback last. No emoji. No “successfully”.

Before — noise

🎉 Woo! Bag processed OK :) status=awesome dest=bangkok? id=null msg="Have a great flight!!" ts=maybe

After — PO complete

BKK  lpn=0217123456  point=LOAD  flt=TG676  date=08SEP26  pax=ARKARA/NON

JSON — same ranks, named domains

{
  "dest": "BKK",
  "lpn": "0217123456",
  "point": "LOAD",
  "flight": "TG676",
  "date": "08SEP26",
  "pax": "ARKARA/NON"
}

Field names are domains. Do not add vibe, emoji, or duplicate dest as cityNamePretty unless a second domain requires it (and then say why in the schema).
