## (d) Service status — the ephemera skin

[`d-ephemera-surface/`](d-ephemera-surface/) shows the same four ranks wearing the skin: vintage domain
inks, an acknowledgement stamp, a handwritten override, a torn incident stub. Every mark declares the
event it records. The primary rows stay straight — only the detached stub rotates.
